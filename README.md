# login_google
Login With Google API
==============================

Script dibawah ini berfungsi untuk membuat proses LOGIN dengan memanfaatkan Google API, Anda dapat memodifikasi script berikut untuk keperluan project anda.

- Sebelum menggunakan script ini, pastikan Anda telah membuat Client ID dan Client Secret Oauth2 Google, Anda dapat membuat kode tersebut pada Google Cloud Console (https://console.cloud.google.com)
- Install API Client Library menggunakan composer, gunakan script berikut : composer require google/apiclient:^2.0
- Folder baru akan tergenerate otomatis dengan nama "vendor" setelah library berhasil terinstall
