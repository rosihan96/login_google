# login_google
Login With Google API
==============================

Script dibawah ini berfungsi untuk membuat proses LOGIN dengan memanfaatkan Google API, Anda dapat memodifikasi script berikut untuk keperluan project anda.

Sebelum menggunakan script ini, pastikan Anda telalh membuat Client ID dan Client Secret Oauth2 Google, Anda dapat membuat kode tersebut pada Google Cloud Console (https://console.cloud.google.com)
